# Нотатки

Маленький вебзастосунок для практичної роботи з Docker. Python-код змінювати не потрібно.

Запуск усередині контейнера: `python app.py`, порт `8000`.

Сторінки: `/` - нотатки, `/info` - стан застосунку у форматі JSON.

Нотатки зберігаються у `data/notes.json`. Назва й автор беруться зі змінних середовища `APP_TITLE` і `AUTHOR`.
